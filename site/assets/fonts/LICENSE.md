# Fonts

Both families are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).

- **Archivo** (Omnibus-Type). `archivo-var-latin.woff2` is a subset (Latin, punctuation, arrows) of the
  Google Fonts variable build, instanced to wght 400–800 and wdth 100–112 with fontTools.
- **DM Mono** (Colophon Foundry). `dm-mono-400-latin.woff2`, `dm-mono-500-latin.woff2`: Google Fonts latin subsets.

The same files as openaudiovisual.com, self-hosted so the page makes no third-party requests.
Chinese text uses the system fonts (PingFang TC, Noto Sans TC).
